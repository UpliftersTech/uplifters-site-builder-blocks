2. Development and build-time dependencies
-------------------------------------------

None of the packages in this section ship inside the published plugin
archive: @wordpress/env and @wordpress/scripts are local tooling only, and
the four @wordpress/* packages imported by the source (block-editor,
components, element, i18n) are externalized by the wp-scripts build to the
WordPress-provided `wp.*` globals rather than bundled into build/.

@wordpress/env
Declared version: ^11.12.0
Usage: Local WordPress development environment tooling only.
Copyright: The WordPress Contributors
License: GNU GPL version 2 or later
Source: https://github.com/WordPress/gutenberg/tree/trunk/packages/env

@wordpress/scripts
Declared version: ^34.0.0
Usage: Build, lint, formatting, and plugin packaging tooling only.
Copyright: The WordPress Contributors
License: GNU GPL version 2 or later
Source: https://github.com/WordPress/gutenberg/tree/trunk/packages/scripts

@wordpress/block-editor
Declared version: ^17.0.0
Usage: Imported by block edit.js source (InspectorControls, useBlockProps, and
related editor UI) for compile-time JSX. wp-scripts externalizes this package
to the wp.blockEditor global that WordPress core already provides, so its
code is not bundled into the compiled build/ output.
Copyright: The WordPress Contributors
License: GNU GPL version 2 or later
Source: https://github.com/WordPress/gutenberg/tree/trunk/packages/block-editor

@wordpress/components
Declared version: ^40.0.0
Usage: Imported by block edit.js and dashboard source (PanelBody, Button,

Copyright: The WordPress Contributors
License: GNU GPL version 2 or later

@wordpress/element
Declared version: ^8.6.0

Copyright: The WordPress Contributors
License: GNU GPL version 2 or later

@wordpress/i18n

5. Other icons and SVG artwork
------------------------------

WordPress Dashicons
Usage: Uplifters Website Builder dashboard navigation, status, device, search, media, and action
icons, plus a handful of block-editor toolbar and inspector controls (passed
as string `icon` props to `@wordpress/components` Button/ToolbarButton/Icon,
which render them as Dashicons). Names used include admin-home,
screenoptions, admin-generic, edit-page, arrow-right-alt2, desktop, tablet,
smartphone, menu-alt3, search, arrow-up-alt2, wordpress, format-image,
no-alt, saved, plus, undo, and video-alt3.
Copyright: WordPress Contributors
License: GNU GPL version 2 or later
Source: https://developer.wordpress.org/resource/dashicons/

Frontend social icons
The Social Icons and Social Share blocks contain inline SVG path data for
Google, Facebook, Instagram, LinkedIn, YouTube, Pinterest, X/Twitter, GitHub,
WhatsApp, TikTok, Reddit, email, and link symbols. The brand paths correspond
to the Font Awesome and Simple Icons families already attributed above. Brand
names and logos remain the property of their respective owners.

Generic inline interface SVGs
Uplifters Website Builder also contains inline SVG markup for search, close, navigation arrows,
accordion controls, media placeholders, post metadata, slide controls, logo
placeholders, and shape dividers. These are part of the Uplifters Website Builder source except
where they reproduce an icon family identified above, in which case the
upstream notice above applies.

Uplifters Website Builder brand artwork
The Uplifters Website Builder admin-sidebar, editor-topbar, plugin-page, and block-category brand
icons are original Uplifters Website Builder assets and are covered by the plugin's GNU GPL
version 2 or later license.
